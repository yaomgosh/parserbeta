# WB Product URL Capture

Chrome Extension для ручного сбора ссылок на карточки Wildberries во время скролла.

## Установка

1. Открой Chrome.
2. Перейди на `chrome://extensions/`.
3. Включи `Developer mode`.
4. Нажми `Load unpacked`.
5. Выбери папку `wb_product_capture_extension`.

## Как пользоваться

1. Открой страницу Wildberries с категорией, поиском или выдачей.
2. Нажми иконку расширения.
3. Нажми `Start capture`.
4. Скролль страницу вручную, как обычно.
5. Когда хватит товаров, нажми `Stop`.
6. Нажми `Export CSV` и сохрани `product_urls.csv`.

CSV будет в формате:

```csv
marketplace,product_url
wildberries,https://www.wildberries.ru/catalog/123456/detail.aspx
```

## Важно

- Расширение не логинится, не кликает и не обходит защиты.
- Оно только читает ссылки, которые уже есть в открытой странице.
- Дубликаты удаляются автоматически.
- Если перейти на другую страницу WB и сбор включен, расширение продолжит добавлять новые ссылки в тот же список.
